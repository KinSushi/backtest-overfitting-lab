# Code of Conduct

## Pledge

In the interest of an open and welcoming environment, we pledge to make participation in this project
a harassment-free experience for everyone.

## Standards

Expected behavior: kind language, respect for differing viewpoints, graceful acceptance of
constructive criticism, focus on what is best for the project.

Unacceptable behavior: sexualized language or imagery, personal attacks, trolling, public or private
harassment, publishing others' private information without consent.

## Enforcement

Maintainers are responsible for clarifying the standards and may remove, edit or reject any
non-conforming contribution. Reports can be sent privately to the repository maintainers; they will
be handled with discretion.

Adapted from the Contributor Covenant (https://www.contributor-covenant.org), condensed version.
